# İrem & Cengiz: Ortanokta Macerası 🎈🐐

İki telefondan birlikte oynanan, dallanan bir macera oyunu.

- Oda kodu ile eşleşme (hesap gerekmez)
- Telefona uygulama gibi kurulur (Android: "Uygulamayı yükle", iPhone: Safari → Paylaş → Ana Ekrana Ekle)
- Ortak durum Firebase Firestore'da tutulur (`config.js`)

Dosyalar: `story.js` (hikâye), `questions.js` (mini oyun soruları), `engine.js` (oyun motoru), `app.js` (arayüz), `shim.js` (Firebase katmanı).
